# 研迹 V2 简化方案

## 产品边界

V2不再做复杂教务平台，只解决一个高频问题：学生每月提交成果，老师及时看见，学院全年追踪。

可见角色只有学生、导师、院长。管理员继续承担数据导入、师生匹配、周期设置和运维工作，但没有前台入口。

## 月报时间规则

| 时间                  | 系统行为             | 学生状态      |
| --------------------- | -------------------- | ------------- |
| 每月开放日至30日23:59 | 可以正常提交         | 待提交        |
| 截止时仍未提交        | 生成唯一短信提醒任务 | 补交中        |
| 截止后24小时内        | 允许补交并标记为补交 | 补交中/已补交 |
| 超过24小时仍未提交    | 不再接受本月提交     | 未完成        |

2月没有30日，因此按2月实际最后一天23:59截止。状态由当前时间动态计算，不靠人工修改。

## 查看与评论

- 每位查看者拥有独立的查看记录；
- 已提交但当前导师未打开：红色；
- 当前导师打开后：自动写入查看时间并显示绿色；
- 评论只有文字，不包含分数、通过、退回等操作；
- 学生添加的其他老师只有查看权限；
- 默认导师和院长可以评论。

## 年度进度颜色

| 颜色   | 含义                 |
| ------ | -------------------- |
| 绿色   | 已提交               |
| 红色   | 超过补交时间仍未提交 |
| 橙色   | 正在24小时补交期     |
| 白灰色 | 本月待提交           |
| 灰色   | 尚未开始             |

导师查看自己的学生，院长查看全院学生并显示对应导师。

## V2新增数据表

- `student_teacher_access`：学生授权其他老师只读查看；
- `submission_reads`：按查看者记录首次与最后查看时间；
- `submission_comments`：不带评分的文字评论；
- `monthly_cycles.missed_remind_at`：短信提醒入队时间；
- `monthly_cycles.grace_deadline_at`：24小时补交截止时间。

数据库迁移位于 `infra/postgres/init/003-simplified-workflow.sql`，演示数据位于 `004-simplified-demo-data.sql`。
